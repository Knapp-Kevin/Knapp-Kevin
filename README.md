## Operating principles

1. **Uncertainty may propose. Authority constrains.** Durable consequences require bounded permission.
2. **Provenance over phrasing.** Where an instruction, memory, artifact, or decision came from matters more than how confidently it is worded.
3. **Negative paths are part of the contract.** Replay, stale state, residual data, partial failure, and unauthorized mutation must have defined behavior.
4. **Evidence should outlive the agent.** Important decisions need inspectable artifacts, not a claim that the model considered them.
